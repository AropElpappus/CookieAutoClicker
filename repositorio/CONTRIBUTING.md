# Cómo contribuir

Las correcciones y explicaciones que faciliten aprender son bienvenidas.

Para reportar un error, describe qué esperabas, qué ocurrió y cómo reproducirlo. Incluye tu versión de Windows y, si ejecutas el código, la versión de Python. Indica si usaste el ejecutable, F6 o Fn + F6 y si estaba activada la posición fija. Copia el mensaje de error si existe, retirando datos personales como tu nombre de usuario en las rutas.

Para proponer un cambio, explica el problema y cómo lo comprobaste. Si afecta a las teclas, comprueba inicio y parada con F6, pulsación mantenida y parada con Esc. Prueba primero a 1 CPS y sin posición fija. No es necesario cambiar otros componentes para corregir un problema puntual.

Para cambios de documentación basta con revisar que las instrucciones correspondan al código.
